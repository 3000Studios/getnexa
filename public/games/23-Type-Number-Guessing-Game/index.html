About Number Guess

Number Guess hides a number and dares you to find it. Every guess returns one clue: higher or lower. The mathematics are beautiful — halving the range each time (binary search) finds any number in the fewest possible guesses, and this game proves it.

How to Play

  • Guess a number in the given range.
  • Each answer tells you higher or lower.
  • Narrow the range with every guess.
  • Find the number in as few guesses as possible.

Tips & Strategy

  • Always guess the middle of the remaining range.
  • Track your proven range — never guess outside it.
  • Seven well-chosen guesses can find any number up to 128.
